# Student Feedback Survey – Ultimez Second Task

A responsive HTML survey form created for the Ultimez "Second Task On Form".

## Features
- Text input and email input
- Multiple-choice radio buttons
- Checkboxes for multiple selections
- Textarea for longer responses
- Rating scale from 1 to 5
- Dropdown menu
- Responsive layout
- Submit confirmation message

## Deployment
Upload `index.html` to a public GitHub repository and enable GitHub Pages.
